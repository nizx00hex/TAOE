# The Art of Exploitation — Practice Repository

This repository contains my practice code, notes, and experiments while studying *Hacking: The Art of Exploitation (2nd Edition)* by Jon Erickson.

The purpose of this repository is educational only — focused on understanding:

* C programming
* Memory management
* Stack behavior
* Debugging with GDB
* Assembly basics
* Shellcode concepts
* Buffer overflows
* Low-level Linux internals

## Disclaimer

All code and experiments are performed in controlled lab environments for learning and research purposes only.

## Topics Covered

* Basic C programs
* Pointer manipulation
* Memory layout analysis
* Stack and heap exploration
* Format string concepts
* Debugging and reverse engineering
* Exploit development fundamentals

## Tools Used

* GCC
* GDB
* Linux
* NASM
* objdump
* hexedit

## Learning Goal

To build a strong foundation in systems programming, reverse engineering, and binary exploitation through hands-on practice.
